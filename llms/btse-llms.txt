# BTSE API Documentation

> Developer documentation for the BTSE API. Covers REST and WebSocket interfaces for Markets, Spot, Futures, Wallet, Earn, OTC, FIX, Spot (Legacy v3.3), Futures (Legacy v2.3), plus authentication, error handling, and client SDKs.

OpenAPI 3.0.3 (REST) and AsyncAPI 2.6.0 (WebSocket) specs are the single source of truth and are served alongside the docs. Production hosts: `api.btse.com` (REST) and `wss://ws.btse.com` (WebSocket). Testnet hosts: `testapi.btse.io` and `wss://testws.btse.io`.

## Getting Started

- [Quickstart](https://docs.btse.com/quickstart): End-to-end first trade — create API keys, sign a request, place an order.
- [Authentication](https://docs.btse.com/authentication): HMAC-SHA384 signing scheme with multi-language examples.
- [Error Codes](https://docs.btse.com/error-codes): HTTP status codes and API-level error reference.
- [WebSocket Guide](https://docs.btse.com/websocket-guide): Connection lifecycle, authentication, reconnection strategy, and topic index.
- [Order Lifecycle](https://docs.btse.com/order-lifecycle): Order states, transitions, and event semantics across REST and WebSocket.
- [Client SDKs](https://docs.btse.com/sdks): Downloadable Python, JavaScript, Java SDKs generated from the OpenAPI specs.
- [Auth Tester](https://docs.btse.com/auth-tester): Interactive signature generator and live request tool.
